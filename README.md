# 网页行为采集与内容清洗平台

面向网页行为录制、脚本化采集、内容清洗与结构化输出的数据采集与加工平台。

这是一个前后端分离的管理平台：前端 Vue 3 + Vite + TypeScript，后端 FastAPI（Python）。
两边各自独立启动，前端 dev server 已关掉自动打开页面，启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端
│   ├── src/views/WorkbenchView.vue|tsx  全部模块共享工作台
│   ├── src/data/modules.ts              18个业务模块配置
│   ├── src/api/              统一请求封装
│   └── vite.config.ts        dev server 配置（open: false）
├── backend/                  FastAPI（Python） 后端
│   ├── app/routers/resource.py  通用查询/导出/登记/动作接口
│   ├── app/services/<key>.py    每个模块独立领域逻辑
│   ├── app/services/base.py     共享服务骨架
│   └── app/store.py          内存数据仓库与示例数据
├── .gitignore
└── docker-compose.yml
```

## 启动

### 后端

```bash
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
./run.sh
```

健康检查：`curl http://127.0.0.1:8000/api/health`

### 前端

```bash
cd frontend
npm ci
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，
需要自己访问。`/api` 由 vite 代理到后端 `http://127.0.0.1:8000`。

## 快照数据集交付（按采集运行）

存档与导出分离，接收方缺少可回放并核对来源的快照数据集。平台支持**按采集运行交付快照数据集**，
打通 `导出通道 → 快照数据集 → 运行历史 → 页面快照`：

- 一次交付是一份自包含 JSON 数据集（`data/deliveries/<dataset_id>.json`，原子落盘、不可变），
  含完整快照、只有预览的旧档，以及一份在导出与回收冲突时仍可读的完整快照。
- 每个条目说清实际可获取的**正文（body）、摘要（summary）、来源（source）和理由（reason）**，
  并标注回放分级：`full`（完整可回放）/ `preview_only`（仅预览旧档）。
- 只有预览的旧档不计入完整回放，进入**待补清单**，可按「原运行 + 采集来源」定位补采。
- 已交付文件的清单（manifest）与实有正文始终一致，随包发布 SHA-256 校验和，篡改即校验失败。
- 导出与回收冲突时，已交付快照只变更本地存档状态、正文随交付文件保留，已完成文件不会变成半包。
- 接收方可下载独立文件导入回放，**重复导入幂等**（按 `dataset_id + 快照编号` 去重），
  页面快照读取同一数据集可验正文并重建可回放条目，旧档不算本次新采集。

接口前缀 `/api/snapshot-delivery`：`build` 构建预览、`publish` 发布、`deliveries` 交付索引、
`runs/{run_id}/scope` 运行交付范围与待补清单、`download` 下载、`verify` 核对、`import`/`import/file`
接收方导入、`entries/{entry_key}/replay` 验正文回放。端到端测试见
`backend/tests/test_snapshot_delivery.py`。

## 约定

- 全部模块共享`frontend/src/views/WorkbenchView.vue|tsx`和一套资源路由。
- 每个模块仍保留独立`backend/app/services/<模块>.py`；纯前端保留
  `frontend/src/domain/<模块>.ts`，用于承载真实业务差异并维持36题位容量。
- 列表接口统一返回 `{ items, total, page, size }`，动作接口统一返回 `{ ok, message }`。
- 状态流转只允许在 `app/services` 里改，路由层不做业务判断。
